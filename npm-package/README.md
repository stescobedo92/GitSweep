# GitSweep CLI for npm

This npm package installs the `gitsweep` command.

```bash
npm install -g @stescobedo9205/gitsweep-cli
gitsweep --help
gitsweep clean --dry-run
```

GitSweep requires the .NET 10 runtime or SDK on the machine running the command.

The source project and full documentation live at https://github.com/stescobedo92/GitSweep.
